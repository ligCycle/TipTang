# หน้าโดเนท: ฟอร์มขึ้นก่อน สองคอลัมน์บนเดสก์ท็อป

วันที่: 2026-09-14 · สถานะ: อนุมัติในแชท (ผู้ใช้เลือกแนวทาง A)

## ปัญหา

หน้า `/[locale]/[username]` (หน้าที่คนดูเปิดเพื่อโดเนท และครีเอเตอร์เอาไปแปะ) เป็นคอลัมน์เดียว
`max-w-2xl` และ**ทุกอย่างเป็น `.card`**: หัวโปรไฟล์ 1 กล่อง · goal 1 กล่อง · อันดับ**กล่องละแถว** ·
ผู้สนับสนุนล่าสุด**กล่องละแถว** · ฟอร์มโดเนทอยู่**ลำดับ 4** ใต้ทั้งหมดนั้น

ผู้ใช้สรุปเอง: *"ทุกอย่างเป็นกล่องเรียงต่อกันยาวเป็นแถว"* และ *"ฟอร์มโดเนทอยู่ลึกเกิน กว่าจะเจอต้องเลื่อน"*
ต้นตอเดียวกัน — หน้าเรียงตามโครงสร้างข้อมูล ไม่ใช่ตามสิ่งที่คนดูมาทำ

## สิ่งที่ต้องได้

1. **ฟอร์มโดเนทเห็นทันที** — เดสก์ท็อป: ใต้หัวโปรไฟล์เลย · มือถือ: บล็อกที่ 2 ถัดจากหัว
2. **ฟอร์มเป็นกล่องเดียวในหน้า** — หัวโปรไฟล์ / goal / อันดับ / ล่าสุด ไม่ใช่กล่องอีกต่อไป
3. เดสก์ท็อป (≥ lg) สองคอลัมน์: ซ้าย = ฟอร์ม (+ร้านค้าเมื่อเปิด) · ขวา = goal, อันดับ, ล่าสุด
4. มือถือ คอลัมน์เดียวเรียง: หัว → ฟอร์ม → goal → อันดับ → ล่าสุด
5. **ไม่แตะข้างใน `TipForm`** (state, QR, อัปสลิป) — เปลี่ยนแค่ตำแหน่งและสิ่งรอบข้าง
6. สีธีมของครีเอเตอร์ (`accent`) ยังใช้ทุกที่เดิม · dark mode ยังใช้ได้ · ครีเอเตอร์ที่อัปโหลด cover ยังเห็นรูป
7. ไม่เพิ่ม i18n · ไม่เพิ่ม dependency · ไม่แตะ API/DB

## ดีไซน์

### โครงหน้า (`src/app/[locale]/[username]/page.tsx` ส่วน `return`)

```
<div class="mx-auto max-w-5xl lg:grid lg:grid-cols-[minmax(0,1fr)_20rem] lg:gap-8 lg:items-start">
  <header  class="lg:col-span-2">        หัวโปรไฟล์ เต็มความกว้าง
  <div     class="mt-6 space-y-8">       คอลัมน์หลัก: TipForm (หรือ notConfigured) · ShopCheckout
  <aside   class="mt-8 space-y-8 lg:mt-6"> แถบข้าง: goal · อันดับ · ล่าสุด
</div>
```

ลำดับ DOM = ลำดับมือถือพอดี (block flow) · บน lg grid วางเป็น header แถวบน, main ซ้าย, aside ขวา
ไม่ใช้ `order-*` ไม่ใช้ sticky (รายการล่าสุดมีได้ถึง 20 แถว sticky จะพัง)

### หัวโปรไฟล์ — ไม่ใช่กล่อง

- Cover เป็นแถบบาง `h-24 sm:h-32 rounded-3xl` พื้น `accentGradient` (หรือรูป cover ถ้ามี `object-cover`)
- ใต้ cover: แถว flex — avatar `h-20 w-20 -mt-10` ซ้อนขอบล่างของ cover (ขอบขาว 4px เหมือนเดิม) ·
  ข้างๆ: ชื่อ `text-2xl sm:text-3xl font-extrabold` + `@handle` สี accent + bio `text-brand-900/70` ·
  โซเชียล: บน sm+ ชิดขวาของแถว บนมือถือ wrap ลงบรรทัดใหม่ (ปุ่มกลม `h-9 w-9` แบบเดิม)
- ไม่มี `.card` ไม่มี `cardTint` ไม่ `text-center`

### คอลัมน์หลัก

`TipForm` เหมือนเดิมทุกประการ (มี `.card rounded-3xl` ของตัวเอง = **กล่องเดียวในหน้า**)
`notConfigured` fallback และ `ShopCheckout` อยู่ใต้มัน

### แถบข้าง — หัวข้อ + รายการ คั่นด้วยเส้น

หัวข้อทุกส่วนสไตล์เดียวกัน: `text-xs font-semibold uppercase tracking-wide text-brand-900/60` + ไอคอน `h-4 w-4`

- **Goal** (เมื่อ `goalAmount > 0`): แถวหัวข้อ (target + ชื่อเป้า, `%` สี accent ชิดขวา) → แถบ `h-2.5` →
  ข้อความ `raised / goal` — ไม่มีกล่อง · ตัวเลข `tabular-nums`
- **อันดับ** (เมื่อมี): `<ol class="divide-y divide-brand-900/10">` แถว `py-2.5 flex gap-3`:
  เลขอันดับ `w-5 text-sm font-black tabular-nums` สี accent · ชื่อ `truncate font-medium` ·
  ยอด `ml-auto text-sm font-semibold tabular-nums` · **อันดับ 1 = `font-bold` เฉยๆ** ไม่มี ring ไม่มีกล่อง
- **ล่าสุด** (เสมอ): `<ul class="divide-y divide-brand-900/10">` แถว `py-3`: บรรทัดแรก ชื่อ + ยอด (`ml-auto tabular-nums`)
  บรรทัดสอง ข้อความ `text-sm text-brand-900/70` ถ้ามี · ว่าง = `<p class="text-sm text-brand-900/50">` ไม่ใช่กล่อง

### สิ่งที่ตัดออก

`cardTint` ถูกใช้ที่หัว/goal/อันดับ/ล่าสุด เท่านั้น → หลังแก้**ไม่มีใครใช้** ลบตัวแปรทิ้ง
(`accentGradient` ยังใช้ที่ cover + avatar · `accentStyle` ยังใช้ที่ root)
`TipForm` รับ `accentColor` แล้วทำ tint ของตัวเองข้างใน ไม่กระทบ

## สิ่งที่ตั้งใจไม่ทำ

- ไม่แก้ข้างใน `TipForm` / `ShopCheckout`
- ไม่ทำ sticky sidebar, ไม่ทำแท็บสลับอันดับ/ล่าสุด, ไม่เปลี่ยนจำนวนรายการ (top 5 / recent 20)
- ไม่แตะหน้า overlay, dashboard, landing

## การทดสอบ (dev server จริง · ไม่ต้องล็อกอิน หน้านี้สาธารณะ)

1. `tsc` · `build` · `lint` **คงที่ 5**
2. **เดสก์ท็อป** (`resize_window` desktop, กว้าง ≥ 1024): เปิด `/th/lig_1569` →
   หัวเต็มความกว้าง · ฟอร์มซ้าย · goal/อันดับ/ล่าสุดขวา · **ฟอร์มเห็นโดยไม่ต้องเลื่อน**
3. **มือถือ** (`resize_window` mobile 375): ลำดับ = หัว → ฟอร์ม → goal → อันดับ → ล่าสุด
   (เช็กจาก DOM order + ไม่มี `order-*`) · ไม่มี scroll แนวนอน
4. **นับกล่อง**: `document.querySelectorAll('.card')` ในหน้าต้องเหลือ **1** (ของ TipForm) — ก่อนแก้มี 1+1+5+9 = 16
5. **ข้อมูลเท่าเดิม**: goal `0% ฿0 / ฿10,000` · อันดับ 5 แถว `เก็ ฿50 … เก๋จ้า ฿1` · ล่าสุด 9 แถว — ตัวเลขทุกตัวเหมือนก่อนแก้
6. **Dark mode** ทั้งสองขนาดจอ · **`nongmewtumarai`** (มี goal, มีทิป) และครีเอเตอร์ที่ไม่มี goal ต้องไม่พัง
7. Console ไม่มี error · **กดปุ่ม "สร้าง QR"** ยังทำงาน (พิสูจน์ว่า TipForm ไม่กระทบ)
